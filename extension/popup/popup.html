Everything runs on this computer. The chart you pick and the text around it go to a local server on localhost:8787, which asks a vision model running in Ollama on localhost:11434. No cloud service is contacted and nothing leaves the machine.

The model only decides what the colours mean. Where those colours are, and what gets drawn, is worked out by the extension itself.

Signing in on the ColorBridge website is optional. It only matters if you sign into a Pro account there — that lifts the 10-per-day limit here. Nothing else about the site affects the extension.
